# 🦀 Técnicas de Programação — Rust

Repositório dedicado aos exercícios, projetos e atividades desenvolvidos durante as aulas da disciplina de **Técnicas de Programação**, no curso de **Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)**.

O objetivo deste repositório é registrar minha evolução na programação utilizando **Rust**, colocando em prática conceitos fundamentais de lógica de programação, estruturas de controle e desenvolvimento de soluções computacionais.

## 📚 Atividades desenvolvidas

Este repositório reúne exercícios e projetos práticos realizados durante as aulas, com foco no aprendizado da linguagem Rust e no desenvolvimento do raciocínio lógico.

**Conteúdos estudados:**

- Variáveis e tipos de dados
- Entrada e saída de informações
- Operadores aritméticos e lógicos
- Estruturas condicionais
- Estruturas de repetição
- Funções e organização do código
- Resolução de problemas utilizando lógica de programação

*Os conteúdos serão atualizados conforme o avanço das aulas e o desenvolvimento de novas atividades.*

## 🛠️ Tecnologias utilizadas

- **Rust** — linguagem de programação utilizada nas atividades
- **Cargo** — ferramenta de gerenciamento de projetos e compilação Rust
- **Git e GitHub** — versionamento e compartilhamento dos códigos

## 🎯 Objetivo do repositório

Documentar meu aprendizado em Rust, praticar os conceitos apresentados na disciplina de Técnicas de Programação e construir um portfólio acadêmico com exercícios e projetos desenvolvidos ao longo do curso.

Este repositório está em constante evolução, acompanhando meu progresso e a aplicação dos conhecimentos adquiridos em sala de aula.
